PROES - Programación en Español

Desarrolla software de la manera más fácil

Nuestro objetivo como plataforma es proporcionar herramientas para el desarrollo web, permitiendo a las personas de habla hispana aprender a desarrollar software de la manera más fácil.

¿En qué me beneficia?

Nuestras herramientas están pensadas para un público que está aprendiendo desarrollo web, por lo cual, te será fácil aprender y practicar con ellas.

¿Cómo puedo contribuir?

Nuestras herramientas son de código abierto, permitiendo a las personas que desean contribuir desarrollar actualizaciones, reportar errores y realizar sugerencias por medio de nuestros repositorios en GitHub.

Ecosistema de proyectos

Herramientas de código abierto listas para usar y explorar.

PIPE

PIPE es un ORM - Mapeador Objeto Relacional desarrollado en PHP, que permite interactuar con el modelo de las tablas en la base de datos accediendo a métodos escritos en español.

PHP ORM Open Source
GitHub → Docs

Escrud

Escrud - CRUD en Español, es una herramienta que genera automáticamente una interfaz para crear, consultar, editar y eliminar registros de una tabla en la base de datos por medio de métodos escritos en español.

HTML CSS JS PHP Open Source
GitHub → Docs

Rutalo

Rutalo es un enrutador desarrollado en PHP, que permite procesar URL limpias y amigables por medio de métodos escritos en español.

PHP Enrutador Open Source
GitHub → Docs
